# Schedule — расписание занятий

## Локальный запуск
1. Распакуйте архив.
2. Откройте папку проекта в VS Code.
3. Откройте `index.html` в браузере или используйте Live Server.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий GitHub с названием `schedule` (или другим удобным названием).
2. Загрузите в корень репозитория `index.html`, а также папки `css/` и `js/`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/ (root)`, затем сохраните.
5. Дождитесь публикации по адресу вида `https://ВАШ-ЛОГИН.github.io/schedule/`.

## Структура
- `index.html` — главная страница.
- `css/styles.css` — оформление, адаптивная сетка, светлая и тёмная темы.
- `js/data.js` — импортированные группы, занятия и настройки учебного календаря.
- `js/app.js` — отображение расписания, навигация по неделям и сохранение настроек.

## Реализовано в этой версии
- Название Schedule в интерфейсе и метаданных страницы.
- Сохранение курса, группы, выбранной недели и выбранного дня в `localStorage`. Ручной выбор типа недели не сохраняется, чтобы старое значение не переопределяло автоматический календарь.
- Восстановление настроек после перезагрузки.
- Автоматическое обновление блока «Сегодня» и календаря при смене даты, возврате на вкладку и фокусе окна.
- Расчёт чередования недель, устойчивый к переходам на летнее/зимнее время.
- Увеличенный футер с кнопками «Связаться» и «Сообщество». Пока они показывают уведомление, потому что реальные ссылки ещё не выбраны.
- Кнопка профиля пока является заглушкой интерфейса, а не настоящей регистрацией.

## Важно: учебный календарь
В исходной Excel-таблице нет календарной привязки числителя/знаменателя. По сообщению пользователя, неделя 12–18 октября 2026 года — числитель, поэтому в `js/data.js` установлены `anchorMonday: "2026-10-12"` и `anchorType: "numerator"`. Чередование рассчитывается от этой недели. Перед долгосрочным использованием желательно сверить её с официальным календарём техникума.

## Что пока не реализовано
- Регистрация, вход и восстановление пароля.
- Серверная база данных.
- Настоящие ссылки связи и сообщества.
- Админские роли, права старост и публикация изменений через интерфейс.

GitHub Pages — только статический хостинг. Когда будем подключать аккаунты и совместное редактирование, потребуется backend/сервис авторизации и база данных. Секретные ключи сервисов нельзя помещать в клиентский JavaScript.
